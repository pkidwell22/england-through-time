# Schema and conventions

All substantive tables below carry `id`, `source_id`, `checked_on`, `confidence`, `evidence_class`, `notes`, `dispute_id`, `start_date_id`, and `end_date_id`. Source and date citations are generated by the loader. Constraints are authoritative in [schema.sql](schema.sql).

## Supporting tables

| Table | Purpose |
|---|---|
| `source` | Title, publisher/author, fetched URL or precise not-fetched bibliography, access status, checked date, source type and lead-only flag. |
| `entity` | Global ID/type/packet registry for referentially checked generic links; not itself a historical assertion. |
| `date_span` | Historical earliest/latest years, generated astronomical years, optional month/day, circa, calendar, precision, qualifier and its own provenance. Bounds describe one uncertain instant; duration uses two date rows. |
| `citation` | Every fact/date entity to one or more sources, with locator, citation role and checked date. |
| `loaded_packet` | Exact input packet SHA-256 and record count; no historical claim. |

## Substantive and workflow tables

| Table | Meaning | Specific fields |
|---|---|---|
| `place` | Named geographic entities; coordinates are anchors with an explicit error radius, never inferred boundaries. | `name`, `kind`, `country`, `lat`, `lon`, `uncertainty_m`, `position_method`, `position_source_id`, `position_note`, `position_confidence` |
| `place_name` | Dated name attestations and languages. Dates describe attestation, not proof of exclusive use. | `place_id`, `name`, `language`, `name_type` |
| `place_phase` | Dated states of a place; population and rank are separate explicitly based estimates. | `place_id`, `phase_type`, `description`, `population_min`, `population_max`, `rank`, `estimate_basis` |
| `person` | Named people; start/end mean birth/death bounds, not reigns. | `name`, `role`, `description` |
| `office` | Institutional offices, including episcopal sees. | `name`, `polity_id`, `place_id`, `office_type` |
| `office_tenure` | A person holding an office; start/end are tenure bounds. | `person_id`, `office_id`, `tenure_note` |
| `polity` | Peoples, political units and administrative jurisdictions; no territorial polygon is implied. | `name`, `kind`, `description` |
| `polity_period` | Dated phases of a polity, including creation and reorganisation. | `polity_id`, `description` |
| `ruler_of` | Sourced reign claims, including overlapping or rival reigns. | `person_id`, `polity_id`, `title`, `tenure_note` |
| `event` | Dated events; start is the bounded occurrence, end is only supplied for an actual duration. | `name`, `event_type`, `place_id`, `description`, `outcome`, `consequences`, `campaign_id` |
| `battle` | Battle detail linked to an event; site security is distinct from whether the battle happened. | `event_id`, `site_security`, `site_note`, `outcome`, `primary_sources` |
| `battle_party` | One belligerent/commander assertion per row; sides are source-specific labels. | `event_id`, `side`, `polity_id`, `commander_id`, `description` |
| `battle_number` | Source-specific numerical claims, not consensus totals; null is not zero. | `event_id`, `side`, `quantity_type`, `min_value`, `max_value`, `unit`, `number_basis`, `reliability` |
| `campaign` | Campaigns and movements, including epidemic spread; paths are not automatically known. | `name`, `description`, `movement_type` |
| `waypoint` | Ordered, dated stops. Connecting lines must not be treated as attested tracks. | `campaign_id`, `sequence`, `place_id`, `event_id`, `action`, `path_certainty`, `interpolation_note` |
| `structure` | Physical buildings or works linked to a place; construction details are separate phases. | `name`, `place_id`, `structure_type`, `description` |
| `structure_phase` | Construction, alteration, use and destruction assertions; dimensions belong only to this phase. | `structure_id`, `phase_type`, `description`, `material`, `length_m`, `width_m`, `height_m`, `builder_id`, `event_id` |
| `route` | Historical route identity, with explicit geometry status; ordered nodes are not a surveyed polyline. | `name`, `route_type`, `description`, `geometry_status` |
| `route_node` | Ordered source-supported route nodes. | `route_id`, `sequence`, `place_id`, `node_note` |
| `timeline_series` | Quantitative series definition and methodology; incompatible estimates stay separate. | `name`, `measure`, `unit`, `geographic_scope`, `methodology` |
| `timeline_value` | Dated quantitative observation/estimate; ranges are bounds, not statistical intervals unless stated. | `series_id`, `value_min`, `value_max`, `value_text`, `basis`, `place_id` |
| `dispute` | Explicit disagreement or interpretive uncertainty. Competing claim rows share dispute_id. | `topic`, `description`, `status` |
| `claim` | A source-specific assertion about any registered entity, including competing scholarly claims. | `subject_id`, `predicate`, `value_text` |
| `relation` | Typed directed link between any two entities; identity links do not erase conflicting claims. | `subject_id`, `predicate`, `object_id`, `description` |
| `app_link` | Comparison to a frozen JSON pointer; corrections, refinements and omissions are explicitly distinguished. | `entity_id`, `app_file`, `app_id`, `json_pointer`, `comparison_type`, `app_claim`, `research_claim`, `importance` |
| `todo` | Research leads, outstanding verification and coverage gaps; these are not established historical facts. | `topic`, `task`, `priority`, `status`, `reason`, `lead_url`, `entity_id` |

## Views

- `fact`: common provenance across all typed fact/date/workflow rows. Exclude `todo` for historical claims and `date_span` when counting independent assertions.
- `event_timeline`: event dates, qualifiers and position anchors. A date field alone must not override its qualifier.
- `movement_timeline`: ordered campaign stops with temporal uncertainty and spatial confidence.
- `place_timeline`: place phases joined to name, coordinate and date context.
- `market_borough_by_1300`: complete-date-band cutoff on parsed IHR market/borough attestations, with qualification flag. It includes grants; it is not an operational market census.
- `app_disagreements`: corrections, uncertainty and refinements, joined to their principal source; omissions/agreements remain in `app_link`.

## Key semantics

`circa` expresses approximation. `earliest_year` and `latest_year` are date bounds, not a probability distribution. `qualifier=at` is an occurrence/observation anchor; `by`, `before` and `after` are one-sided bounds. When a source says only “early century,” the indexing bracket and its conventional nature must be stated in notes. Unknown time remains null rather than year zero.

`person.start/end` mean birth/death. `ruler_of` and `office_tenure` use tenure bounds. `polity_period`, phases and campaigns describe durations where both references are supplied. `timeline_value` may use start/end for a decadal aggregation; it must not be plotted as one annual measurement.

Coordinates use latitude/longitude degrees in WGS84. The uncertainty radius is a conservative locator envelope unless stated otherwise, not a calibrated 95% error interval. `unlocated` requires null coordinates/radius. Climate grid cells are explicitly `kind=climate_grid_cell`; they must not become settlement icons.

IDs prefixed `pr-`, `em-`, `lm-` and `x-` preserve provenance of research batches. Duplicate historical identities can be linked without overwriting different source assertions. Source conflicts use `dispute_id`; separate rows retain each claim and its source. No unlabelled consensus is inferred by the loader.

Foreign keys, typed relation endpoints, allowed evidence/confidence values and no-year-zero conversion are validated. Original source existence, interpretation and publication rights remain research questions beyond structural SQL validity.
